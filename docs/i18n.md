# KORbuild — idioma (inglês e português)

Decidido em outubro de 2026: **o produto é em inglês (padrão)** e o português fica como opção, com o botão **PT | EN** na tela de entrada e no menu do usuário. A escolha fica no aparelho (`localStorage`, chave `kbt.idioma`).

## Como funciona

| Peça | O que faz |
| --- | --- |
| `js/i18n.js` | `tr('frase em português')` devolve a frase no idioma escolhido; `tn(n, 'singular', 'plural')` para contagens; variáveis entre chaves: `tr('Prazo: {hora}', { hora })` |
| `js/i18n-en.js` | Dicionário inglês. A chave é a frase em português, exatamente como está no código |
| `js/util.js` | Formatos por idioma: data (07/10/2026 · 10/07/2026), hora (16:30 · 4:30 PM), hora cheia (18h · 6 PM), número decimal, distância (km · mi/ft), clima (°C e mm · °F e in) |
| `js/crew.js` `dinheiro()` | US$ 1.234,56 (pt) · $1,234.56 (en) |
| Dados de demonstração | Nascem no idioma escolhido. Na tela de entrada, trocar o idioma recria a demonstração; com alguém logado, só a interface muda |

Trocar o idioma recarrega a página (os textos fixos dos módulos são lidos ao carregar).

## Regras para código novo

1. **Todo texto que a pessoa vê passa por `tr()` ou `tn()`**, inclusive toasts, títulos de diálogo, `title`, `aria-label` e `placeholder`.
2. **Frase inteira, não pedaços.** Use variáveis: `tr('RDO nº {numero} de {obra} aprovado', { numero, obra })`, e não `'RDO nº ' + n + ' de ' + obra`. A ordem das palavras muda de um idioma para o outro.
3. **Contagem com `tn()`**: `tn(n, '{n} pessoa', '{n} pessoas')`.
4. **Nunca traduzir o que é dado ou código**: ids, classes CSS, nomes de variáveis das fórmulas (`MeasuredArea`), códigos de item, cost codes, e-mails e endereços.
5. **Datas, horas, dinheiro e medidas** só pelas funções de `js/util.js` e `dinheiro()`; nada de `.replace('.', ',')` solto.
6. Depois de escrever, rode:
   - `node tools/i18n-faltando.mjs`: lista as frases sem inglês;
   - acrescente o inglês com `python3 tools/i18n-adicionar.py "Seção" < traducoes.json`;
   - `node tests/ingles.test.mjs http://localhost:8123/`: percorre as telas em inglês e acusa português.
