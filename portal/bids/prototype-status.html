Prototype status

⤓ Download Word

The prototype (the demo with sample data) shows the product working. Beside it, the real account already runs bidding on the cloud database and is in homologation. This page says what is real today and what is still simulated in the demo.

Already running on the database (real account)

Item How it works today
Where bids live On the server, in the contracting company's tables. Each invitee receives only its own invitation, its own bids and the messages it may see; it never sees who else was invited or the other amounts. Every action after sending (extend, invite more, addendum, answer, bid, award, cancel) goes through a database function that checks who is calling.
Invitations for companies without an account The invitation link is generated by the database when you send (only its hash is stored) and shown once, to copy; it stays saved on the device that sent it. The invitation is also emailed to the invitee (see Notifications and email).
The link page Opens without signing in: the invitee sees the package and the drawings, answers, asks questions and sends the bid with the PDF. When it creates its account with the same email, the invitation, messages and bids come along.
Drawings The PDFs go to the bid's folder in the company's cloud storage. I'll quote copies each drawing into the invited company's own project, sheet by sheet.
Bid PDF Stored with the bid, in the bid's folder, for the contracting company to download.
Award and the linked job Awarding marks the winner's project as won; Create job from this project opens the job form filled in and the job is created already linked to the contracting company's job, which turns on daily reports, schedule and site presence between the two companies.
Channel Questions, answers (to everyone or only to who asked), notices to everyone and the job channel after the award, all recorded and never edited.
Sub-tier subcontracting Bids opened from a project or a won job, with the policy set by the company above (allowed, with approval, not allowed); the approval request shows only the chosen company, never the amount.

Simulated today (in the demo)

Item In the prototype In the product
Where bids live In the browser, in a place shared by the demo companies. The server, with each company reading only what it may see — already running in the real account.
Invitations by email Not sent. The contracting company uses Copy the link for invitees without an account. Sent by email, with the private link — already running in the real account.
Drawings Only the PDF file names are kept; the invited project starts without sheets. The PDFs go with the invitation and become the sheets of the invited company's project — already running.
Bid PDF Only the file name is kept. Stored with the bid — already running.
Budget by cost code Exists in the engine; the form takes only the total. A budget field per cost code.
Use in my estimate The sub's price goes into the proposal as other items, with your markups. A subcontractor line in the catalog, by cost code.
Attachments in the channel Text only. Photos and PDFs.
