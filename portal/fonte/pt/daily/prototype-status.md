# Situação do protótipo

O protótipo mostra o produto funcionando com dados de exemplo. Algumas coisas são simuladas porque ainda não há servidor. Esta página lista essas coisas, para ninguém prometer mais do que existe — e para o cliente saber o que vem por aí.

## Simulado hoje

| Item | No protótipo | No produto |
|---|---|---|
| Onde ficam os dados | Só no navegador de cada aparelho. O celular do campo e o computador do escritório não veem os dados um do outro. | Um banco de dados na nuvem, separado por empresa; todos veem os mesmos dados. |
| Lembretes das 16h e das 18h | Só com o app aberto. | Enviados pelo servidor, mesmo com o app fechado. |
| **Melhorar texto** | Regras simples no celular. | Inteligência artificial, guardando o texto original ao lado. |
| PDF | Impresso pelo navegador (**Salvar como PDF**). | Gerado no servidor, pronto para baixar. |
| Link do cliente | Abre só no mesmo navegador. | Abre em qualquer lugar. |
| Falta de sinal | Simulada tocando em **Online**. | Real. |
| Entrada | Usuários de exemplo, sem senha. | E-mail e senha da empresa. |
| Clima | Real (Open-Meteo), quando há internet. | Igual. |

## O que vem depois

| Item | Observações |
|---|---|
| Contas dos clientes no banco de dados | A página de entrada principal está pronta; as contas chegam com o banco de dados. |
| Aplicativos nas lojas (App Store, Google Play) | Previstos; o protótipo já se instala na tela inicial. |
| Configurar prazo e horários dos lembretes | A confirmar. |
| Lembretes por SMS e e-mail | Avaliados depois (regras dos EUA para SMS de empresas). |
| A construtora convida a prestadora (concorrência) e um canal entre as duas | Especificado; chega com o banco de dados. |
