# Situação do protótipo

O que é simulado no protótipo hoje, e o que vem depois.

## Simulado hoje

| Item | No protótipo | No produto |
|---|---|---|
| Onde ficam as concorrências | No navegador, num lugar comum às empresas de exemplo. | No servidor, e cada empresa lê só o que pode ver. |
| Convites por e-mail | Não são enviados. A contratante usa **Copiar o link** para quem não tem conta. | Enviados por e-mail, com o link pessoal. |
| Desenhos | Guarda só o nome dos PDFs; o projeto da convidada começa sem folhas. | Os PDFs vão com o convite e viram as folhas do projeto da convidada. |
| PDF da proposta | Guarda só o nome do arquivo. | Guardado com a proposta, para a contratante baixar. |
| Orçamento por etapa | Existe no motor; o formulário pede só o total. | Um campo de orçamento por etapa. |
| *Usar no meu orçamento* | O preço da quarteirizada entra na proposta como **outros itens**, com as suas margens. | Uma linha de subempreiteiro no catálogo, por etapa. |
| Anexos no canal | Só texto. | Fotos e PDFs. |

## O que vem depois

| Item | Observações |
|---|---|
| Envelope fechado | A contratante só vê os valores depois do prazo (comum em obra pública). |
| Aditivo a partir do canal | Uma mensagem vira um pedido de mudança formal (*change order*). |
| Dividir o fechamento | Fechar etapas diferentes com prestadoras diferentes. |
| Convidar só pelo e-mail | Convidar quem ainda não está nos Contatos. |
| Conta a partir do link | Quando a prestadora cria a conta com o e-mail do convite, o convite, as mensagens e as propostas passam para ela. |
