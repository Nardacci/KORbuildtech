Prototype status

⤓ Download Word

The prototype shows the product working with sample data. A few things are simulated because there is no server yet. This page lists them, so nobody promises more than exists — and so the customer knows what is coming.

Simulated today

Item In the prototype In the product
Where the data lives Only in the browser of each device. The field's phone and the office's computer do not see each other's data. A cloud database, separated by company; everyone sees the same data.
Reminders at 4 PM and 6 PM Only while the app is open. Sent by the server, even with the app closed.
Improve text Simple rules on the phone. AI, keeping the original text alongside.
PDF Printed from the browser (Save as PDF). Generated on the server, ready to download.
Client link Opens only in the same browser. Opens anywhere.
Losing signal Simulated by tapping Online. Real.
Sign-in Demo users, no password. Company email and password.
Weather Real (Open-Meteo), when there is internet. Same.
